# AethelionCS

AethelionCS is a CloudStream extension repository focusing on Turkish streaming providers.

## Repository Setup
To add this repository to CloudStream:
1. Open CloudStream Settings -> Extensions.
2. Add Repository: `https://raw.githubusercontent.com/KorhanWithSunglasses/AethelionCS_Alpha/builds/plugins.json`

## Providers
- **DiziBoxProvider:** Foreign TV series provider with dynamic multi-server discovery (DBX Pro, Moly+, Odnok, etc.).

## Build
```bash
./gradlew make makePluginsJson
```
