# AethelionCS

AethelionCS is a CloudStream extension repository focusing on Turkish streaming providers.

## Repository Setup
To add this repository to CloudStream:
1. Open CloudStream Settings -> Extensions.
2. Add Repository: `https://raw.githubusercontent.com/user/AethelionCS/builds/plugins.json`

## Providers
- **DiziBoxProvider:** Fast foreign TV series provider with dynamic multi-server discovery (DBX Pro, Moly+, Odnok).

## Build
```bash
./gradlew make makePluginsJson
```
