# CHANGE PLANNING SKILL

## Plan Template
```text
PROBLEM: [Clear statement of the defect or requirement]
OBSERVATION: [Empirical evidence demonstrating the issue]
ROOT_CAUSE_STATUS: [IDENTIFIED / HYPOTHESIS / UNKNOWN]
PROPOSED_CHANGE: [Minimal surgical modification description]
FILES: [List of files to modify]
RISKS: [Potential side effects or regressions]
TEST_PLAN: [Specific automated and runtime tests to execute]
ROLLBACK: [Strategy to revert if unexpected regressions occur]
```
