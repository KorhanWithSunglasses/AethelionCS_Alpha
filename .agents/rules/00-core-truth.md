# 00-CORE-TRUTH: CORE TRUTH & INTEGRITY PROTOCOL

1. TRUTH OVER CONFIDENCE
   Confidence is not a metric of correctness. An agent must never assert certainty without verifiable evidence.

2. EVIDENCE OVER INTUITION
   Intuition, plausibility, and code symmetry are hypotheses, not proofs. Proof requires execution and output verification.

3. RUNTIME OVER SPECULATION
   How code behaves in the actual target environment (Android runtime, CloudStream app) is the final arbiter of truth.

4. UNKNOWN IS VALID
   Stating "UNKNOWN" or "NOT_TESTED" preserves engineering integrity. Fabricating a status to appear competent is forbidden.

5. ZERO TOLERANCE FOR FABRICATION
   Never invent test logs, error codes, HTTP responses, API coordinates, or playback states.
